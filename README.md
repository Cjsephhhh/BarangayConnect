# BarangayConnect

A web-based guided dispute resolution and case management system for barangays.

## Project Increment 1 — User Accounts and Authentication

This repository contains the React frontend and Spring Boot REST API for resident registration, secure login/logout, role-based access, and role-specific dashboards.

## Stack
- React + Vite
- Java 17 + Spring Boot 3.5.x
- Spring Security + JWT
- PostgreSQL

Implementation files are being added on the `increment-1-auth` branch.
